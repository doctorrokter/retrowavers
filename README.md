Qt/C++ retrowave radio app for BlackBerry 10

## Store art

BlackBerry World's listing (uploaded to the store, not packed): `store_icon.png` - the app's own
`icon_480_x_480.png`, as it is - and `store_banner.png` (1920 x 1186, the "Feature image"): that icon on
a synthwave night, with the stock BB10 glyph `ic_music.png` flying round it. Drawn by bb-shared's
`gen-art.js`, from this folder:

```bash
node ../bb-shared/tools/gen-art.js --colors "#9c19c2,#06affb" --glyph ic_music.png --icon-file icon_480_x_480.png --only store --banner-colors "#0b020e,#1a0524@50%,#3d0a52" --title "Retrowavers: The Legacy"
```
